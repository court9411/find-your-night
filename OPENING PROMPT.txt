## THE APP
Users open the app, enter their city (or use GPS location), pick a vibe 
(drinks, live music, dancing, rooftop, etc.) and AI finds real local venues 
and experiences for them tonight. Clean, fast, built for mobile.

## TECH STACK
- Next.js 14 (App Router)
- Tailwind CSS
- Supabase (user accounts + database)
- Anthropic Claude API — claude-sonnet-4-20250514 (for AI venue search)
- Vercel (deployment)

## DESIGN SYSTEM
Dark, bold, cinematic — late-night city energy.
- Background: #09090F
- Primary accent: #FF6B35 (orange like city lights)
- Text: white
- Fonts: "Bebas Neue" for all headings, "Outfit" for body text (Google Fonts)
- Cards: rounded 16px, glass effect, subtle border rgba(255,255,255,0.08)
- Background: subtle radial gradients suggesting city lights/bokeh
- Everything mobile-first — most users will be on their phones

## CORE USER FLOW
1. Landing screen — big bold app name "FIND YOUR NIGHT", tagline, get started button
2. Location — text input for city name as PRIMARY method. Also try GPS but 
   show the manual text input immediately since GPS is unreliable in browsers.
   (e.g. "Chicago", "Cincinnati", "Miami")
3. Vibe selector — 8 large tappable cards:
   🍸 Drinks & Bars, 🎵 Live Music, 🕺 Night Out, 🍕 Late Night Eats,
   🌃 Rooftop Vibes, 🎮 Casual Fun, 🎭 Arts & Events, 🎲 Surprise Me
4. Loading screen — animated, shows vibe emoji + "Scanning the city..."
5. Results — 5 venue cards with: name, type, neighborhood, description, 
   why tonight, price range ($|$$|$$$), tags

## AI INTEGRATION (CRITICAL — DO THIS RIGHT)
- Create a Next.js API route at /api/search (server-side only)
- NEVER put the Anthropic API key in frontend code
- Call claude-sonnet-4-20250514 with this prompt pattern:
  "You are a local nightlife guide. Suggest 5 real venues in [city]

   [{name, type, neighborhood, description, whyTonight, price, tags}]"
